🖼️ Image to PDF

JPG ve PNG formatındaki görsellerinizi saniyeler içinde tek bir PDF dosyasına dönüştürün.

📖 Proje Hakkında

Image to PDF, bilgisayarınızdaki .jpg, .jpeg ve .png uzantılı görselleri hızlı, pratik ve kalite kaybı yaşamadan PDF belgesine dönüştürmek için Python ile geliştirilmiş hafif bir araçtır. Tek bir görseli veya birden fazla görseli sırayla birleştirerek düzenli PDF dosyaları oluşturabilirsiniz.

✨ Özellikler

🖼️ Format Desteği: Yaygın olarak kullanılan JPG, JPEG ve PNG görselleriyle tam uyumludur.

⚡ Hızlı Dönüştürme: Görselleri saniyeler içinde işleyerek PDF çıktısı oluşturur.

📄 Çoklu Görsel Birleştirme: Birden fazla resmi tek bir PDF dosyası altında toplayabilirsiniz.

🪶 Hafif ve Pratik: Karmaşık kurulumlar gerektirmez, sade bir yapıya sahiptir.

🔒 Çevrimdışı Çalışma: Tüm işlemler yerel bilgisayarınızda gerçekleşir; dosyalarınız internet ortamına yüklenmez.

🛠️ Kurulum

Projeyi bilgisayarınızda çalıştırmak için işletim sisteminize uygun adımları takip edebilirsiniz.

🪟 Windows

Projeyi klonlayın ve klasöre girin:

git clone https://github.com/savascimustafaa/image_to_pdf.git
cd image_to_pdf


Sanal ortam oluşturun ve etkinleştirin:

python -m venv venv
venv\Scripts\activate


Gerekli kütüphaneleri yükleyin:

pip install -r requirements.txt


🐧 Linux / macOS

Projeyi klonlayın ve klasöre girin:

git clone https://github.com/savascimustafaa/image_to_pdf.git
cd image_to_pdf


Sanal ortam oluşturun ve etkinleştirin:

python3 -m venv venv
source venv/bin/activate


Gerekli kütüphaneleri yükleyin:

pip install -r requirements.txt


💻 Kullanım

Kurulum tamamlandıktan sonra uygulamayı aşağıdaki komutla başlatabilirsiniz:

python main.py


(Ana dosyanızın adı farklıysa main.py kısmını kendi dosya adınızla değiştirebilirsiniz.)
